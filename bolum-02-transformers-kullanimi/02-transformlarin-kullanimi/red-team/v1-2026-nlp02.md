# NLP Zafiyet Testleri

Bu proje, dil modellerinde sık görülen zafiyetleri ve davranışsal hata tiplerini incelemek için hazırlanmış Jupyter notebook'larından oluşur. Amaç, modelin farklı girdi ve tokenizer davranışları karşısında nasıl hataya düştüğünü görsel ve adım adım inceleyebilmektir.

Projede yer alan örnekler arasında şunlar bulunur:

- `Sequence_Order_Bias.ipynb`
- `TOKENIZER_SENSIVITY.ipynb`
- `Truncation_Blindness.ipynb`
- `Unmasked_Padding_Drift.ipynb`
- `model-failure-analysis/` klasöründeki model hata analizi notları

Bu notebook'lar, genellikle `jupyter notebook` komutuyla çalıştırılır ve tarayıcı üzerinden adım adım incelenebilir.

---

## Hızlı Başlangıç

Aşağıdaki adımları sırayla takip edin:

1. Proje klasörüne gidin.
2. Sanal ortam oluşturun.
3. Ortamı aktive edin.
4. Gerekli paketleri kurun.
5. `jupyter notebook` ile çalıştırın.
6. Tarayıcıda ilgili `.ipynb` dosyasını açın.

---

## 1) Sanal Ortam Oluşturma

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

İsterseniz aşağıdaki komutu da çalıştırarak Python sürümünü kontrol edebilirsiniz:

```bash
python --version
```

Çıktıda mutlaka Python 3.x.x görünmelidir.

---

## 2) Gerekli Paketleri Kurma

Proje kök klasöründe iken şu komutu çalıştırın:

```bash
pip install -r requirements.txt
```

Bu komut, notebook'ların çalışması için gerekli tüm bağımlılıkları kuracaktır.

Eğer paket kurulumunda eksik kalan bir şey olursa, tek tek şu komutları da çalıştırabilirsiniz:

```bash
pip install ipykernel
```

```bash
pip install sentencepiece protobuf
```

Not: Bazı örneklerde `torch`, `transformers` ve `sentencepiece` gibi paketler özellikle gerekecektir. Eğer yeni bir temiz ortam kuruyorsanız şu komut da kullanılabilir:

```bash
pip install jupyter torch transformers sentencepiece protobuf
```

---

## 3) Jupyter ile Çalıştırma

Projeyi `jupyter notebook` komutuyla çalıştırmak en doğrusudur:

```bash
jupyter notebook
```

Bu komut çalıştığında varsayılan tarayıcıda Jupyter arayüzü açılacaktır. Oradan proje klasöründeki `.ipynb` dosyalarını seçerek çalıştırabilirsiniz.

Özellikle bu dizin yapısında notebook dosyaları olduğu için, proje doğrudan `jupyter notebook` ile açılmaya uygundur.

---

## 4) Jupyter Kernel Sorunları ve Çözüm Yolları

### 1. Kernel görünmüyor / "Python (venv)" yok

Eğer Jupyter içinde sanal ortamınızın kernel'ı görünmüyorsa şu komutları çalıştırın:

```bash
pip install ipykernel
python -m ipykernel install --user --name=venv --display-name="Python (venv)"
```

Bu komut, kullanıcı bazında bir Jupyter kernel ekler. Sonrasında Jupyter sayfasını yenileyin.

Eğer eski bir kernel kalmışsa ve karışıklık varsa şu komutu kullanabilirsiniz:

```bash
jupyter kernelspec uninstall venv -y
```

Sonra tekrar:

```bash
python -m ipykernel install --user --name=venv --display-name="Python (venv)"
```

### 2. Notebook içinde `ModuleNotFoundError` hatası alıyorsam

Bu durum genellikle sanal ortamın aktif olmadığı veya paketlerin kurulmadığı anlamına gelir. Aşağıdakileri kontrol edin:

```bash
python --version
pip list
```

Daha sonra:

```bash
pip install -r requirements.txt
```

Yalnızca notebook içinde eksik paket varsa:

```python
!pip install sentencepiece protobuf
```

şeklinde hücre içinde kurulum da yapılabilir.

### 3. `jupyter: command not found` hatası

Bu durumda Jupyter kurulu değildir. Aşağıdaki komutla kurulum yapın:

```bash
pip install jupyter
```

veya yeni sanal ortamda:

```bash
pip install jupyter torch transformers sentencepiece protobuf
```

### 4. `torch` veya `transformers` bulunamıyor

Bunu şu komutla kurabilirsiniz:

```bash
pip install torch transformers
```

### 5. Notebook açıldı ama kernel çöktü

Bu olay genellikle paket uyumsuzluğu, eski kernel veya eksik bağımlılıktan kaynaklanır. Şu adımları deneyin:

```bash
pip install -r requirements.txt
pip install ipykernel
python -m ipykernel install --user --name=venv --display-name="Python (venv)"
```

Sonrasında Jupyter'i yeniden başlatın.
