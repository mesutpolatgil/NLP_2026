# NER · Kod

```python
from transformers import pipeline
ner = pipeline("token-classification",
    model="dslim/bert-base-NER",
    aggregation_strategy="simple", device=-1)
text = ("My name is Wolfgang and I live in Berlin. "
        "I work for Microsoft.")
for entity in ner(text):
    print(entity["word"], entity["entity_group"])
```

# Çeviri · Kod

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM
tok = AutoTokenizer.from_pretrained("google-t5/t5-small")
model = AutoModelForSeq2SeqLM.from_pretrained("google-t5/t5-small")
```

# Q12 · Cevap ve gerekçe

<p class="note">Bölüm 7.3 MLM değerlendirmesi</p>

Model aynı olsa da değerlendirilen hedef konumları değiştiği için aynı tahmin problemi ölçülmemiştir. Doğrulama verisine maskelemeyi bir kez uygulayıp oluşan `input_ids`, `attention_mask` ve `labels` alanlarını saklarım; değerlendirmede yeniden maskelemeyen bir collator kullanırım. Eğitimde dinamik maskeleme devam edebilir. Tekrar değerlendirmede aynı bozulmuş girdilerin ve hedeflerin kullanıldığını; seçilen konumların özgün token kimliklerini hedeflediğini, diğer hedeflerin `-100` ile dışlandığını kontrol ederim.
