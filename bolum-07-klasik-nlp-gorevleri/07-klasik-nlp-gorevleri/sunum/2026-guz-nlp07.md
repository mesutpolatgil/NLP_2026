# İsimlendirilmiş varlık tanıma

<div class="legend"><span><b>PER</b><br>Kişi</span><span><b>LOC</b><br>Yer</span><span><b>ORG</b><br>Kurum</span></div>

Model her varlık için **tür** ve **metindeki aralığı** bulur.

`aggregation_strategy="simple"`, alt kelime tahminlerini varlık aralıklarında birleştirir.

# NER · Kod

```python
from transformers import pipeline
ner = pipeline("token-classification",
    model="dslim/bert-base-NER",
    aggregation_strategy="simple", device=-1)
text = ("My name is Wolfgang and I live in Berlin. "
        "I work for Microsoft.")
for entity in ner(text):
    print(entity["word"], entity["entity_group"])
```

<div class="flow"><div class="unit"><b>İngilizce</b><small>The house is wonderful.</small></div><span class="arrow">→</span><div class="unit"><b>T5</b><small>translate English to German:<br>görev öneki</small></div><span class="arrow">→</span><div class="unit"><b>Almanca</b><small>Das Haus ist wunderbar.</small></div></div>

# Çeviri · Kod

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM
tok = AutoTokenizer.from_pretrained("google-t5/t5-small")
model = AutoModelForSeq2SeqLM.from_pretrained("google-t5/t5-small")
model.eval()
x = tok("translate English to German: The house is wonderful.",
        return_tensors="pt")
y = model.generate(**x, max_new_tokens=56,
                   num_beams=4, do_sample=False)
print(tok.decode(y[0], skip_special_tokens=True))
```

document = (
