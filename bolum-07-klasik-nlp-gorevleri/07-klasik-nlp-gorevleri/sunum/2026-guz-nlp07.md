# Mimariler ve görevler

## Berk Talha Aslan

**Sistem Mimarı**

Bir görev için neden encoder, decoder veya encoder-decoder seçiyoruz?

---

# Encoder

**BERT / DistilBERT ailesi**

Metnin görünür bölümlerini birlikte temsil eder.

| Girdi | İşlem | Çıktı |
|---|---|---|
| Token dizisi | İki yönlü bağlam temsili | Token başına vektör |

Bu vektörlere farklı çıktı katmanları eklenebilir: varlık etiketi, maske tahmini veya cevap başlangıcı/bitişi.

<!-- Berk tahtada metin, encoder ve çıktı katmanını üç adımda çizebilir. -->

---

# Causal decoder

**GPT ailesi**

Her adım, daha önceki tokenları kullanarak **sonraki tokenı** tahmin eder.

```text
Natural language processing is
Natural language processing is a
Natural language processing is a common
```

Bu diziler çalışma mantığını gösterir. Modelin devamı doğrulanmış bilgi garantisi vermez.

---

# Encoder-decoder

**T5 / BART ailesi**

Encoder kaynak metni temsil eder. Decoder, kaynak temsiline ve önceki hedef tokenlara bakarak yeni dizi üretir.

| Kaynak | Görev | Hedef |
|---|---|---|
| The house is wonderful. | Çeviri | Das Haus ist wunderbar. |
| Uzun belge | Özetleme | Kısa belge |

Kaynak ve hedefin token sayıları eşit olmak zorunda değildir.

---

# Mimari seçimi

| İhtiyaç | Bu gösterimdeki yaklaşım |
|---|---|
| Her token için etiket | Encoder + token sınıflandırıcı |
| Maskeli tokenı bulmak | Encoder + sözcük dağarcığı çıktısı |
| Bağlamdan cevap aralığı | Encoder + başlangıç/bitiş çıktısı |
| Kaynaktan yeni metin | Encoder-decoder |
| Metni devam ettirmek | Causal decoder |

Bunlar dersin kurulumlarıdır. Her görevin tek olası çözümü oldukları iddia edilmez.

# 1 · İsimlendirilmiş varlık tanıma

**Problem:** Metindeki kişi, yer ve kurumları bulmak.

> My name is **Wolfgang** and I live in **Berlin**. I work for **Microsoft**.

Varlık türü kadar **metindeki aralığı** da önemlidir.

`aggregation_strategy="simple"`, alt kelime tahminlerini varlık aralıklarında birleştirir.

---

# NER · Kod

```python
from transformers import pipeline
ner = pipeline("token-classification",
    model="dslim/bert-base-NER",
    aggregation_strategy="simple", device=-1)
text = ("My name is Wolfgang and I live in Berlin. "
        "I work for Microsoft.")
for entity in ner(text):
    print(entity["word"], entity["entity_group"])
```

**Bir sonraki sayfa:** Bu girdi için kaydedilen varlıklar.

---

# NER · Gerçek çıktı

```text
Wolfgang PER
Berlin LOC
Microsoft ORG
```

**PER:** kişi · **LOC:** yer · **ORG:** kurum

Model doğru türleri buldu. Tek cümle, modelin genel doğruluğunu veya Türkçe başarısını ölçmez.

# 2 · Maskeli dil modelleme

> Paris is the **[MASK]** of France.

# MLM · Kod

```python
fill = pipeline("fill-mask",
    model="distilbert/distilbert-base-uncased",
    device=-1)

print(best["token_str"])
print(round(best["score"], 6))
```

Decoder, hedef dili token token üretir. Kaynak ve hedef ayrı dizilerdir.

# Çeviri · Kod

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM
tok = AutoTokenizer.from_pretrained("google-t5/t5-small")
model = AutoModelForSeq2SeqLM.from_pretrained("google-t5/t5-small")
model.eval()
x = tok("translate English to German: The house is wonderful.",
        return_tensors="pt")
y = model.generate(**x, max_new_tokens=56,
                   num_beams=4, do_sample=False)
print(tok.decode(y[0], skip_special_tokens=True))
```

# Özetleme · Kod

T5 modeli ve tokenizerı önceki çeviri sayfasından kullanılır.

```python
document = (
    "The city library opened a new reading room on Monday. "
    "The room has 40 seats and is open to all students. "
    "The library said that no fee is required to use the room.")
x = tok("summarize: " + document, return_tensors="pt",
        truncation=True, max_length=512)
y = model.generate(**x, max_new_tokens=56,
                   num_beams=4, do_sample=False)
print(tok.decode(y[0], skip_special_tokens=True))
```

# 5 · Causal dil modelleme

**Problem:** Önceki tokenlardan sonraki tokenı üretmek.

Başlangıç metni:

```text
Natural language processing is
```

Üretimin akıcı olması, içerikteki iddiaların doğrulandığı anlamına gelmez.

---

# Causal LM · Kod

```python
from transformers import AutoModelForCausalLM
tok = AutoTokenizer.from_pretrained("distilbert/distilgpt2")
model = AutoModelForCausalLM.from_pretrained("distilbert/distilgpt2")
model.eval()
x = tok("Natural language processing is", return_tensors="pt")
y = model.generate(**x, max_new_tokens=45, do_sample=False,
    pad_token_id=tok.eos_token_id, repetition_penalty=1.15)
print(tok.decode(y[0], skip_special_tokens=True))
```

# 6 · Extractive question answering

**Bağlam**

> The researcher studied at **Ankara University**. She later worked in Berlin.

**Soru**

> Where did the researcher study?

Model yeni bir açıklama yazmak yerine bağlam içindeki bir **cevap aralığını** seçer.

---

# QA · Kod

```python
qa = pipeline("question-answering",
    model="distilbert/distilbert-base-cased-distilled-squad",
    device=-1)
context = ("The researcher studied at Ankara University. "
           "She later worked in Berlin.")
answer = qa(question="Where did the researcher study?",
            context=context)
print(answer["answer"], answer["start"], answer["end"])
```

---

# QA · Gerçek çıktı

```text
Ankara University 26 43
```

`context[26:43]` cevabın kendisidir.

**26 dâhil, 43 hariç:** pipeline karakter aralığını verir. Eğitimde başlangıç ve bitiş hedefleri token konumlarıdır.

Uzun bağlamda **pencereleme, offset ve son işleme** ayrıca kontrol edilmelidir.

# Soru 1 · Cevap

## B · Ayşe kişi, Ankara yer

İstenen çıktı, metindeki **varlık aralığı ve türüdür**.

Bu nedenle görev, isimlendirilmiş varlık tanıma olarak kurulabilir.

# Soru 2 · Cevap

## D · Her iddia kesin doğrudur

Metin örtüşmesi, iddiaların kaynak tarafından desteklendiğini tek başına göstermez.

“Ölüm **olmadı**” ifadesindeki bir olumsuzluğun kaybolması, anlamı tersine çevirebilir.

# Soru 3 · Hedef dışlama

Doğru etiket dizisi:

```text
[-100, 1, -100, 2, -100]
```

Bozulmuş etiket dizisi:

```text
[0, 1, -100, 2, 0]
```

Loss hesabına katılan hedef sayısı neden **2'den 4'e** çıkar?

<!-- Kaynak: ekip sorusu Q10. -->

---

# Soru 3 · Cevap

**`-100`:** bu loss kurulumunda hedef dışlama.\
**`0`:** gerçek sınıf etiketi, örneğin `O`.

İlk ve son konumlar `0` yapıldığında iki ek hedef eğitime katılır.

Düzeltme: bu konumları yeniden `-100` yapıp **hizalamayı, aktif hedef sayısını ve gradyan konumlarını** kontrol ederiz.
