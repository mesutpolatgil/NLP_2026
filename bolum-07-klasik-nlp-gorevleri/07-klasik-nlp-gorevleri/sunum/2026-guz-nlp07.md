# Etiketleri tokenlara taşıma

| Konum | Kaynağın uyguladığı politika |
|---|---|
| Özel token | Hedef `-100`: loss dışında |
| Sözcüğün ilk tokenı | Sözcüğün özgün etiketi |
| Devam alt kelimesi | Aynı tür; gerekiyorsa `B-` → `I-` |

```text
[3, 0, 7, 0, 0, 0, 7, 0, 0]
[-100, 3, 0, 7, 0, 0, 0, 7, 0, 0, 0, -100]
```
